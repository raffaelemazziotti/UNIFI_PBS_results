# PBS modulo 1

Pagina statica per la consultazione dei risultati del modulo 1: statistiche aggregate, distribuzione dei voti, ricerca per matricola e dettaglio dei dodici punteggi. 

Aprire [docs/index.html](docs/index.html) nel browser, oppure servire la cartella:

```sh
python3 -m http.server 8080 --directory docs
```

La pagina non richiede un backend, cookie, account, servizi esterni o dipendenze JavaScript.
